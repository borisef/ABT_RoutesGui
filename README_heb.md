# מדריך למשתמש — ABT Flight Route Builder

## מה הכלי עושה

הכלי מאפשר ליצור ולערוך קובצי הוראות טיסה בפורמט JSON, לדמות את המסלול ולהציג אותו בגרף. אפשר לבנות מסלול באמצעות הוראות טיסה ישירות או באמצעות נקודות ציון, ולבדוק את התוצאה מול מגבלות כלי הטיס.

**חשוב:** הגרף והבדיקות מבוססים על מודל סימולציה. הם אינם מבטיחים ביצועי טיסה של כלי טיס אמיתי, ואינם תחליף לבדיקה ולאישור לפני שימוש מבצעי.

## הפעלה

- **ללא התקנה:** הפעילו את `FlightRouteGui.exe` מתוך תיקיית הכלי. בגרסה זו אין צורך להתקין Python במחשב.
- **באמצעות Python:** התקינו Python 3.9 ומעלה, פתחו PowerShell בתיקיית הכלי והריצו:

  ```powershell
  python -m pip install -r requirements.txt
  python FlightRouteGui.py
  ```

  Tkinter, שבו משתמש הממשק, כלול בדרך כלל בהתקנת Python ל-Windows.

## היכרות עם הממשק

בצד שמאל נמצאים הגדרות המסלול, רשימת ההוראות או נקודות הציון, מצב התחלתי, קובץ מגבלות הטיסה והודעות מצב. בצד ימין מוצגים המסלול במבט על ופרופיל הגובה.

### בחירת מערכת קואורדינטות

בחרו `Coordinate type`:

- **BAT** — קואורדינטות מקומיות במטרים: North, East, Down.
- **GEO** — קו רוחב וקו אורך במעלות עשרוניות (WGS84) עבור נקודת ההתחלה, נקודות הציון ומיקום הסוללה. הכלי ממיר אותן למערכת מקומית לצורך הסימולציה. המודל הגאוגרפי מקומי ואינו הקרנה למפה עולמית.

בכל המצבים, `Down` נמדד במטרים כלפי מטה: ערך שלילי פירושו גובה מעל נקודת הייחוס. כיוון `0°` הוא צפון, וזוויות כיוון גדלות עם כיוון השעון. גלגול חיובי פונה ימינה ועלרוד חיובי גורם לעלייה.

### מצב התחלתי ומיקום הסוללה

ב־`Initial state` הזינו את מצב כלי הטיס בתחילת הסימולציה:

- מיקום North/East/Down (או קו רוחב/אורך ב־GEO)
- Roll, Pitch, Heading ו־Speed
- `End time [s]` — משך הסימולציה. אפשר להשאיר ריק כדי להשתמש במשך ברירת המחדל.

ב־`Battery position` אפשר להזין מיקום North/East, או קו רוחב/אורך ב־GEO. יש למלא את שני הערכים או להשאיר את שניהם ריקים. המיקום מסומן בגרף ואינו משנה את מסלול הטיסה המדומה.

## יצירת מסלול באמצעות הוראות ישירות

בחרו בלשונית `Direct instructions`. כל שורה בטבלה היא הוראה שמתחילה בזמן נתון ונשארת בתוקף עד ההוראה הבאה.

הזינו את ערכי ההוראה:

| שדה בממשק | משמעות |
|---|---|
| `Start [s]` | זמן תחילת ההוראה בשניות; חייב להיות 0 ומעלה, ולא יכול להיות זהה לזמן של הוראה אחרת. |
| `Bank [°]` | זווית הגלגול המבוקשת; חיובית לפנייה ימינה ושלילית לשמאלה. |
| `Roll rate [°/s]` | קצב שינוי הגלגול; יש להזין 0 ומעלה. |
| `Pitch [°]` | זווית העלרוד המבוקשת; חיובית לעלייה. |
| `Pitch rate [°/s]` | קצב שינוי העלרוד; יש להזין 0 ומעלה. |
| `Speed [m/s]` | מהירות היעד; חייבת להיות גדולה מ־0. |
| `Accel [m/s²]` | תאוצה; יש להזין 0 ומעלה. |

לחצו `Add` כדי להוסיף הוראה. כדי לערוך הוראה, בחרו אותה בטבלה, עדכנו את הערכים ולחצו `Update selected`. לחצו `Delete selected` למחיקת ההוראה שנבחרה, או `Clear all` למחיקת כולן. הטבלה מוצגת לפי זמן התחלה.

אפשר להשאיר את שדות היעד האופציונליים ריקים:

- `Turn to azimuth [°]` — הכלי יוסיף הוראות שמסיימות את הפנייה בכיוון המבוקש. יש לבחור זווית Bank שאינה 0 כדי לקבוע את כיוון הפנייה.
- `Level at altitude [m] (neg = up)` — הכלי יוסיף הוראה שמיישרת את העלרוד בגובה המבוקש. השדה משתמש בסימן של Down: ערך שלילי הוא מעל נקודת הייחוס. היעד חייב להיות בר־השגה בהתאם לזווית ולקצב העלרוד.

אפשר לשלב בין שני היעדים. הוראה עם יעד אוטומטי צריכה להתחיל אחרי כל ההוראות שכבר הוזנו. בעת עדכון הוראה קיימת, ניתן לסמן `Shift following segments by` ולהזין שינוי זמן בשניות: ערך חיובי דוחה את ההוראות הבאות ושלילי מקדים אותן.

## יצירת מסלול באמצעות נקודות ציון

בחרו בלשונית `Waypoints`. לכל נקודת ציון הזינו:

- `North`, `East`, `Down` (או קו רוחב/אורך במצב GEO)
- `Azimuth` — כיוון היעד במעלות
- `Speed` — מהירות היעד במטר לשנייה

הגדרות `Incoming-leg limits` שייכות למקטע **שמוביל אל נקודת הציון**. לאחר הזנת הערכים לחצו `Add`. בחרו נקודה ברשימה כדי לערוך אותה (`Update selected`), למחוק אותה (`Delete selected`) או לשנות את סדרה (`Move up` / `Move down`). סדר הנקודות קובע את סדר הטיסה. הכלי יוצר מחדש את הוראות הטיסה בעקבות שינוי בנקודות.

במצב זה אפשר לראות את מיקומי נקודות הציון גם לפני יצירת הוראות. לחצו `Plot route` כדי ליצור או לעדכן את ההוראות ולהציג את המסלול.

## בדיקת התוצאה והמגבלות

לחצו `Plot route` כדי לחשב ולהציג את המסלול. הגרף העליון מציג את המסלול במבט על; הגרף התחתון מציג גובה לאורך זמן. באזור ההודעות מופיעים מיקום הסיום, אזהרות מגבלות, ובמצב נקודות ציון גם שגיאות התקרבות וכיוון.

להגדלה או הקטנה, גלגלו את העכבר מעל אחד הגרפים. כדי להזיז את התצוגה, גררו עם לחצן העכבר השמאלי. `Reset view` מחזיר לתצוגה המקורית.

### קובץ מאפייני כלי הטיס

הכלי טוען אוטומטית את `DataFiles\ABT_FlightCharacteristics\ABT0.json` אם הוא מוצא אותו. אם לא, לחצו `Browse...` באזור `Flight limits` ובחרו קובץ מאפיינים תקין. הקובץ צריך להכיל מערך `Flight_Characteristics` עם רשומה ראשונה ובה ערכי מגבלות כגון זוויות וקצבי גלגול ועלרוד, מהירות ותאוצה. לחצו `None` כדי לנטרל את בדיקת המגבלות.

מגבלות שאינן עומדות בהן מוצגות כאזהרות; הן אינן חוסמות עריכה או שמירה. כאשר לא נטען קובץ מגבלות, הכלי מציין שהבדיקה אינה זמינה. יש להתייחס לאזהרות ברצינות ולאמת את הערכים מול מאפייני כלי הטיס.

## פתיחה, שמירה וייצוא

- `New` יוצר מסלול ריק; `Open...` פותח קובץ JSON קיים.
- `Save` שומר בקובץ הנוכחי; למסלול חדש תיפתח בקשת בחירת מיקום. `Save As...` שומר בשם או במיקום אחר.
- שמירת מסלול דורשת לפחות הוראת טיסה אחת. במסלול נקודות ציון, ההוראות נוצרות מחדש בעת השמירה.
- `Export plot image...` בתפריט `File` מייצא את הגרפים לקובץ PNG, SVG או PDF.
- כוכבית בכותרת החלון מציינת שינויים שלא נשמרו. בעת פתיחת קובץ אחר, יצירת מסלול חדש או יציאה, הכלי שואל אם לשמור את השינויים.

קובץ המסלול שומר את סוג המסלול, סוג הקואורדינטות, המיקום ההתחלתי, ההוראות שנוצרו, ובמידת הצורך גם נקודות הציון ומיקום הסוללה.
